# 하루금융 · 우리 반 투자 연구소

학생들이 뉴스 속 단서를 바탕으로 가설을 세우고, 분기 실적을 비교하며 투자 판단을 돌아보는 가상 금융시장입니다. 기존 게임방·계정·거래·가격을 유지하는 추가 마이그레이션을 사용합니다.

## 수업 흐름

1. 교사가 게임방을 만들고 QR/방 코드를 안내합니다.
2. 학생이 기업 정보, 뉴스와 사전에 공개된 실적 예상치를 읽습니다.
3. 현재 가격으로 즉시 매수·매도하거나 현금·예금을 유지합니다. 수수료와 최종 결제/수령액을 거래 전에 확인하고, 근거 기사를 연결할 수 있습니다.
4. 거래 이유는 투자 기록으로 자동 저장됩니다. 같은 기록에 배운 점, 걱정거리와 다시 확인할 시점을 덧붙입니다. 거래 없이 남기는 판단도 지원하며 최초 판단 문장은 유지합니다.
5. 학생이 ‘오늘 선택 완료’를 누르면 교사 화면에 표시됩니다. 이후 거래나 예금 가입·해지를 성공하면 자동으로 선택 중으로 돌아갑니다. 교사는 ‘오늘 마치고 다음 날 열기’ 한 번으로 진행하며, ‘마감만 하고 토론하기’로 잠시 멈출 수도 있습니다.
6. 6·12·18·24일차 시작에 20개 기업의 분기 실적이 공개됩니다. 실적 반응은 그날 가격에 반영되므로 발표 후 예전 가격으로 거래할 수 없습니다.

## 기업·뉴스·가격의 연결

- 각 기업은 매출, 영업이익률, 현금, 부채와 성장 흐름을 갖습니다.
- 매일 기업 뉴스 6건, 산업 기사 1건, 학습 브리핑 1건과 예정된 후속 기사가 생성됩니다. 각 업종의 기업을 순환해 다룹니다.
- 계약·수요·비용·연구·공급 사건은 단기·다음 분기·연말의 예상 영향 기간을 갖고, 중간 점검·지연·확인·예상 반전으로 이어집니다. 준비 비용은 먼저 발생할 수 있고, 실제 운영 효과는 정해진 기간에만 적용됩니다. 분기 재무 수치는 해당 여섯 날의 영업 기록을 모아 계산합니다.
- 일반 기사에 대한 기대는 다음 거래일에 일부 반영되며, 실제 매출·비용은 단기·다음 분기·연말의 사업 기간에 반영됩니다. 예전 기사도 나중 실적의 근거로 연결됩니다. 분기 실적 발표에 대한 가격 반응은 공개 당일 반영됩니다.
- 시장 예상은 분기 전에 고정해 공개하며, 실제 영업이익과 비교합니다. 이전 실적보다 성장하더라도 시장 예상보다 부족할 수 있습니다.
- 교사가 선택하는 긍정·중립·부정 분위기는 다음 거래일 새 기사의 확률 분포를 바꿉니다. 기업의 성공과 수익률을 보장하지 않습니다.
- 기사·후속 사건·재무정보는 규칙 기반의 가상 생성입니다. 외부 생성형 AI/API 키를 사용하지 않습니다. 봉차트의 고가·저가는 일일 확정 가격을 바탕으로 구성한 교육용 값입니다.

### v8 · 숫자로 읽는 뉴스와 시장 도우미

- 새 기사의 회사 전체 매출 변화율, 이익률 변화(%p), 준비 비용과 운영 기간을 먼저 확정하고, 실제 사업 효과도 같은 공개 숫자에서 계산합니다. 목표와 확인 결과는 각각의 기사에 남으며, 실적에는 운영 일수·초기 가동률·다른 사업을 함께 합산합니다.
- 사건의 가격 반응은 기존 기대와 새 정보의 차이로 계산합니다. 같은 수치·일정의 단순 진행 보도에는 추가 가격 보상이 없습니다. 사업이 개선돼도 목표에 못 미치면 해당 사건의 가격 반응이 음수가 될 수 있습니다.
- 분기 시작의 **당초 예상**은 그대로 보관합니다. 별도의 **현재 기대**는 공개된 사업 목표·준비 비용·일정과 확인 결과로 갱신됩니다. 실적 발표의 가격 반응은 발표 직전 기대와 실제 결과의 차이를 사용해 이미 알려진 영업 효과의 중복 보상을 줄입니다.
- 뉴스룸은 핵심 5건·사건별 보기·전체 기사를 제공합니다. 사건별 기사와 관련 실적을 함께 살펴볼 수 있습니다.
- 경제 기자 **모아**, 기업 연구원 **다온**, 시장 관찰자 **누리**는 학생에게 공개된 정보만 요약합니다. 원래 기사·실적·기업 화면으로 연결되며, 매매를 실행하거나 미래 결과를 읽지 않습니다.
- 거래 흐름은 **해당 게임방 최근 3거래일의 실제 체결금액** 순입니다. 체결 건수와 매수·매도 수량을 익명 집계합니다. 거래가 없으면 없다고 표시하며 가상 NPC 거래를 섞지 않습니다.
- 기존 기사·가격·계좌·당초 예상치는 수정하지 않습니다. 이전 버전에서 이미 진행 중인 사건은 원래 규칙으로 마무리하고, 새로 발생하는 사건부터 새 모델을 사용합니다. 예금 10%와 가격 제한폭은 유지합니다. 거래 수수료는 아래 v9 규칙을 적용합니다.

### v9 · 수업 흐름과 거래비용

- 학생 주 메뉴는 오늘의 소식 / 투자하기 / 내 자산 / 투자 기록, 교사 주 메뉴는 수업 진행 / 학생 현황 / 운영 설정입니다. 뉴스·실적, 예금, 입출금 내역은 관련 화면의 내부 탭으로 이동합니다.
- 기업 화면의 기본 탭은 뉴스·사업이며 실적·차트는 같은 화면에서 전환합니다. 수량·이유·기사 선택은 탭을 바꾸어도 보존합니다. NPC, 상세 필터, 추가 재무지표는 필요할 때 펼칩니다.
- `/api/admin/advance`는 마감·다음 날 생성·만기 처리를 한 트랜잭션으로 수행합니다. 화면의 날짜와 상태를 검사해 중복 요청이 날짜를 두 번 넘기지 못하게 하며, 24일차에는 한 번만 최종 결산합니다.
- 주식·ETF·채권·금의 매수와 매도마다 **0.015%**, 원 단위 반올림(정확히 0.5원은 올림), **최소 1원**을 적용합니다. 예금에는 거래 수수료가 없고 게임에서 세금을 부과하지 않습니다. 실제 시장의 상품별 비용 전체를 재현하는 규칙은 아닙니다.
- 요율은 [키움증권 공식 국내주식 안내](https://www1.kiwoom.com/h/domestic/stock/VStockMainView?dummyVal=0)의 온라인 현금주식 수수료를 참고했습니다(2026-11-05 확인). 반올림·최소금액·다른 상품 공통 적용은 게임의 규칙입니다.
- 수수료는 매수 시 결제액과 보유상품 매입금액에 포함하고 매도 시 수령액에서 차감합니다. 별도 원장과 주문에 실제 금액을 남깁니다. 총자산·수익률·누적 수수료에도 반영되며 과거 체결에 소급 부과하지 않습니다.
- 거래 시 표시된 날짜와 가격도 서버에서 검사해, 교사가 다음 날로 진행한 사이 이전 결제액으로 주문하는 것을 막습니다.
- 기존 데이터는 유지하며 `orders.fee`, `investment_notes.order_id`만 추가합니다. 기존 거래의 돌아보기를 처음 열 때에도 원래 거래일·이유·기사를 연결하며 같은 거래의 노트를 중복 생성하지 않습니다.

## 확인과 운영

학생 화면 미리 체험은 메모리 안에서 생성하며 실제 데이터베이스에 게임방이나 학생을 만들지 않습니다. 교사는 실제 학생의 홈·자산·은행·뉴스·실적·투자 노트를 읽기 전용으로 확인할 수 있습니다. 기사 열람·근거 연결 거래·가설·돌아보기 횟수는 활동 참고 지표이며 판단의 질이나 이해도를 자동으로 평가하지 않습니다.

```bash
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
```

환경변수 `HARU_DB`로 SQLite 저장 경로를, `PUBLIC_BASE_URL`로 학생 참가 QR의 HTTPS 주소를 지정합니다. 기존 Railway `/data` 볼륨을 유지합니다.

```bash
pip install pytest httpx
python -m pytest -q
```

검증 범위: 24일 전체 진행, 네 번의 실적 공개, 사전 예상치 고정, 즉시 체결과 하루 마감, 투자 근거·돌아보기, 동시 주문의 잔액 보장, 다른 방과 역할 간 접근 분리, 재시작 후 데이터 보존, 체험 화면의 실제 데이터 무변경.
