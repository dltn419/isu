# 하루금융 · 우리 반 투자 연구소

학생들이 뉴스 속 단서를 바탕으로 가설을 세우고, 분기 실적을 비교하며 투자 판단을 돌아보는 가상 금융시장입니다. 기존 게임방·계정·거래·가격을 유지하는 추가 마이그레이션을 사용합니다.

## 수업 흐름

1. 교사가 게임방을 만들고 QR/방 코드를 안내합니다.
2. 학생이 기업 정보, 뉴스와 사전에 공개된 실적 예상치를 읽습니다.
3. 현재 가격으로 즉시 매수·매도하거나 현금·예금을 유지합니다. 선택한 근거 기사를 거래에 연결할 수 있습니다.
4. 투자 노트에 예상, 위험과 다시 확인할 시점을 기록합니다. 저장한 최초 판단은 고정되며 돌아보기만 수정할 수 있습니다.
5. 학생이 하루 마감을 누르면 교사 화면에 완료 현황이 표시됩니다. 교사는 원하는 때 장을 마감하고 다음 거래일을 시작합니다.
6. 6·12·18·24일차 시작에 20개 기업의 분기 실적이 공개됩니다. 실적 반응은 그날 가격에 반영되므로 발표 후 예전 가격으로 거래할 수 없습니다.

## 기업·뉴스·가격의 연결

- 각 기업은 매출, 영업이익률, 현금, 부채와 성장 흐름을 갖습니다.
- 매일 기업 뉴스 6건, 산업 기사 1건, 학습 브리핑 1건과 예정된 후속 기사가 생성됩니다. 각 업종의 기업을 순환해 다룹니다.
- 계약·수요·비용·연구·공급 사건은 진행, 지연, 확인 또는 예상 반전으로 이어집니다. 확정된 결과는 매출·이익률을 바꾸고 분기 재무 수치에 반영됩니다.
- 일반 기사의 가격 효과는 다음 거래일에 적용됩니다. 분기 실적 발표에 대한 가격 반응은 공개 당일 반영됩니다.
- 시장 예상은 분기 전에 고정해 공개하며, 실제 영업이익과 비교합니다. 이전 실적보다 성장하더라도 시장 예상보다 부족할 수 있습니다.
- 교사가 선택하는 긍정·중립·부정 분위기는 다음 거래일 새 기사의 확률 분포를 바꿉니다. 기업의 성공과 수익률을 보장하지 않습니다.
- 기사·후속 사건·재무정보는 규칙 기반의 가상 생성입니다. 외부 생성형 AI/API 키를 사용하지 않습니다. 봉차트의 고가·저가는 일일 확정 가격을 바탕으로 구성한 교육용 값입니다.

## 확인과 운영

학생 화면 미리 체험은 메모리 안에서 생성하며 실제 데이터베이스에 게임방이나 학생을 만들지 않습니다. 교사는 실제 학생의 홈·자산·은행·뉴스·실적·투자 노트를 읽기 전용으로 확인할 수 있습니다. 기사 열람·근거 연결 거래·가설·돌아보기 횟수는 활동 참고 지표이며 판단의 질이나 이해도를 자동으로 평가하지 않습니다.

```bash
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 8000
```

환경변수 `HARU_DB`로 SQLite 저장 경로를, `PUBLIC_BASE_URL`로 학생 참가 QR의 HTTPS 주소를 지정합니다. 기존 Railway `/data` 볼륨을 유지합니다.

```bash
pip install pytest httpx
python -m pytest -q
```

검증 범위: 24일 전체 진행, 네 번의 실적 공개, 사전 예상치 고정, 즉시 체결과 하루 마감, 투자 근거·돌아보기, 동시 주문의 잔액 보장, 다른 방과 역할 간 접근 분리, 재시작 후 데이터 보존, 체험 화면의 실제 데이터 무변경.
